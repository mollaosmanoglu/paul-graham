### Users

<Note kind="essay" source="Before the Startup" href="http://www.paulgraham.com/before.html" date="2014-10">
The way to succeed in a startup is not to be an expert on startups, but to be an expert on your users and the problem you're solving for them.
</Note>

<Note kind="tweet" source="@paulg" href="https://x.com/paulg/status/1201946168663654406" date="2019-12">
Don't start a startup where you need to go through someone else to get users.
</Note>

<Note kind="tweet" source="@paulg" href="https://x.com/paulg/status/1231575395679526913" date="2020-02">
If you start a startup that can only reach users by doing deals with big companies, the default outcome will be that you run out of money and die while waiting for them to make up their minds.
</Note>
